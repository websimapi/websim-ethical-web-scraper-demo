# Ethical Web Scraper Demo

A Node.js application demonstrating responsible web automation with Playwright. This project shows how to build a product price comparison tool that ethically scrapes data from e-commerce websites.

## 🚀 Features

- **Playwright-based automation**: Uses modern headless browser technology
- **Ethical scraping practices**: 
  - Rate limiting and request throttling
  - Random delays between requests
  - User-agent rotation to mimic normal browser behavior
  - Proper error handling and retries
- **Response caching**: Minimizes request load on target websites
- **Simple REST API**: Easy to integrate with your own front-end
- **Complete UI example**: Includes a search interface to demonstrate functionality

## 📋 Prerequisites

- Node.js 14.x or higher
- npm or yarn
